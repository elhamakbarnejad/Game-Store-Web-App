🔵Game Store Web App🔵

A responsive game listing web application built with React.
Users can browse games, filter by genre, and view detailed information about each title.

Features:

- Responsive design for mobile, tablet, and desktop
- Game listing with cards
- Filters for genre
- Detailed page for each game
- Fast navigation using React Router
- Modern UI built with Tailwind CSS

Tech Stack:

- React
- React Router
- Tailwind CSS
- React Icons
- Axios (for API requests)

Installation:

- Clone the repository: git clone <repository-url>
- Go to the project folder: cd game-store
- Install dependencies: npm install
- Run the development server: npm run dev

Notes:

- The project is fully responsive and optimized for different screen sizes.
- Filters are implemented using the RAWG API and can filter games by genre and platform.
